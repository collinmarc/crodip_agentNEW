# Runtime Manager 2.3.0-RC15

## Objet
Support des téléchargements Docker Desktop lents.

## Changements
- timeout global RC14 supprimé ;
- timeout d'inactivité observable : 900 s ;
- progression affichée toutes les 15 s ;
- durée maximale absolue désactivée par défaut ;
- activité observée via stdout, stderr et temps CPU Winget ;
- logs et protection contre Winget concurrent conservés ;
- corrections RC9 à RC14 conservées.
